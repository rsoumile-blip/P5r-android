# P5R Android 0.5.15 — NCE

## Touch controls

- **Fixed sticks:** choose Floating or Fixed in the launcher. Fixed mode anchors both movement and camera sticks at their on-screen positions while keeping both touch-responsive.
- **In-game control editor:** tap the gear beside `+` to open it without leaving the game session. Drag controls to reposition them, tap a control to hide or restore it, and use Save, Cancel, or Reset. The d-pad and A/B/X/Y move as groups; each stick anchor can be positioned independently.
- The editor button stays available while gameplay buttons are hidden. Hidden stick guides do not disable stick input.
- The gear has been moved closer to `+` so the in-game editor is easier to find.

## Also included

Smart Performance Profiles with Manual restoration, async pipeline option, launcher controller navigation, thermal pacing, Play History, launcher personalization and animations, user-managed LayeredFS mods, and double-Back exit confirmation.

## Performance adjustment

- Android now lets the system scheduler place frame-critical threads by default. Core pinning remains available for controlled testing with `NX_AFFINITY`; the Snapdragon 685 / Adreno 610 tuning notes found the previous forced fast-core setting neutral to slightly slower.
