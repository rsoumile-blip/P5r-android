# P5R Android 0.5.14 — NCE

## New in this build

- **Install your own mods:** use Files → Data → Install to select a LayeredFS ZIP archive containing a `romfs` folder. The launcher checks archive paths and installs the files under the game's `mods` directory.
- **Manage installed mods:** view compatible installed mods and tap one to enable or disable it. Restart the game for changes to take effect. Mods are not bundled or recommended by the app; users choose their own archives.
- **Double-Back game exit:** the first phone Back press warns, “Unsaved progress may be lost. Press Back again to exit.” Press Back again within 2.5 seconds to close the game and return to the launcher.

Also includes the launcher additions from 0.5.13: controller navigation, thermal pacing, Play History, Smart Performance Profiles, launcher backgrounds and motion, tab sound, optional haptics, refreshed design and icon, and lightweight animations.
