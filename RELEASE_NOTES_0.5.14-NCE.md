# P5R Android 0.5.14 — NCE

## New in this build

- **Install your own mods:** use Files → Data → Install to select a LayeredFS ZIP archive containing a `romfs` folder. The launcher checks archive paths and installs the files under the game's `mods` directory.
- **Manage installed mods:** view compatible installed mods and tap one to enable or disable it. Restart the game for changes to take effect. Mods are not bundled or recommended by the app; users choose their own archives.
- **Double-Back game exit:** the first phone Back press warns, “Unsaved progress may be lost. Press Back again to exit.” Press Back again within 2.5 seconds to close the game and return to the launcher.
- **Device setup suggestion:** the launcher detects the handset model and offers an optional, cautious resolution and 30 FPS starting point. If a custom GPU driver is imported, accepting also switches this game to Android's system Vulkan driver for the next launch; it does not delete the imported driver. Smart Performance Profiles remain separate. Unknown devices receive a conservative suggestion and are not marked as verified.
- **Fixed touch sticks:** optionally pin both the movement stick and camera stick to fixed locations. They still work normally when pressed; floating sticks remain available.
- **In-game touch layout editor:** tap the small settings control beside `+` to open the editor, drag controls (the d-pad and face buttons move as groups), tap a control to hide/show it, then Save, Cancel, or Reset. Stick anchors can be moved; hiding a stick anchor hides its guide but keeps the stick working.

Also includes the launcher additions from 0.5.13: controller navigation, thermal pacing, Play History, Smart Performance Profiles, launcher backgrounds and motion, tab sound, optional haptics, refreshed design and icon, and lightweight animations.

These device suggestions improve setup but cannot guarantee that every Android GPU, driver, or game scene is glitch-free. The Snapdragon 8 Elite/Turnip freeze and audio report still needs a log from that exact device to diagnose.
