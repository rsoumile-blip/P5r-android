# P5R Android 0.5.13 — NCE

## New in this build

- **Launcher controller navigation:** use a controller to move focus, select settings, switch launcher pages and subtabs, return to Display, and start the game. Gameplay controller handling is unchanged.
- **Thermal pacing:** optional launcher control lowers the frame cap temporarily when Android reports severe thermal status, and restores the configured cap as the phone cools. It does not change resolution, textures, or other graphics settings. Performance and thermal behavior depend on the device.
